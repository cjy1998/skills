# 竖屏科普视频制作

## 明确本次范围

- 确认主题、受众、平台、期望时长、资料、头像/账号署名；只问仍会影响制作的事项。未指定尺寸时建议 1080×1920、30 fps；时长是目标，不保证整稿自然口播能压到两分钟。
- 区分“先写稿”“试听”“只看封面/片尾”“导出整片”。只完成获准阶段；认可试听不等于授权做整片，认可封面不等于授权合片。
- 新选题确认视觉方向和音色，不强制沿用参考成片的配色或音色。沿用同一任务风格时，不重复询问。
- 安装依赖、下载语音识别模型、调用收费接口、上传真人参考音频分别取得授权。不要要求在聊天中粘贴密钥，不自动发布、提交或推送。

## 分阶段工作流

1. **核实资料与口播稿**：先核实产品能力、限制、版本、价格和时效。用“熟悉场景 → 概念 → 合适/不合适的任务 → 制作/使用 → 总结与提问”组织内容。写成自然聊天，适量提问，少用讲义式分点；避免误导承诺。给用户审稿。
2. **分镜与视觉样稿**：一幕只讲一个层次；按语义拆幕，不按固定秒数切音频。确定背景、正文、辅助字、强调色、标题层级、图标线宽和字幕区域；先展示一张内容页样稿再批量扩展。封面、正文、片尾复用同一视觉系统，允许信息密度不同。
3. **音色与跨幕试听**：先用短稿试听候选音色；再用已选音色制作覆盖至少三个分镜的连续样片，听开头、切页、中段与结尾。确认模型确实支持选定 voice；不能用参数相同、响度归一、HTTP 200 或解码通过代替听感验收。无法听音频时明确说明并请用户确认。
4. **完整旁白**：获得整片制作授权后，尽量连续生成整篇；长度超过当前模型能力时再设计分块与同声音锚定，不能逐幕独立随机生成并宣称声音一致。完整性失败先核对 ASR、波形和实际尾句，不自动重复付费、不偷换音色、不删掉整片原稿来掩盖截断。
5. **字幕与时间轴**：以原稿显示字幕，用本地 ASR 的字词时间戳对齐；变更音频后按源文件 SHA 失效缓存。先核对开头、末句、总体与每幕覆盖，再确定切页。保留完整单轨旁白，仅切画面；不为每幕额外插入静音。见 references/audio-and-captions.md。
6. **封面与关注片尾**：输出独立封面 PNG；按用户提供的头像制作约 4 秒关注动画，先交独立 MP4 审稿。账号未提供时不编造账号名。参考片尾采用头像弹入、关注按钮轻点、短扩散圈；默认不增加未确认的旁白或背景音乐。封面是平台封面，未经明确要求不当作开场插入视频。
7. **渲染与质量检查**：使用独立输出文件名，保留已确认旧版。渲染后检查每幕关键帧、最长字幕、拼接位置及最终帧；在浏览器实际播放首、中、尾和跨切页，监控错误。调用 scripts/verify_video.py 验证编码、帧数和全片解码；工具结果不等于视觉/听觉验收。
8. **合片与交付**：只有用户明确要求最终合并时才接入关注片尾。无声片尾可使用 scripts/merge_outro.py 保留正文 AAC 和画面编码；有声片尾或编码不兼容时必须走完整渲染方案。提供最终 MP4、独立封面、可选 SRT 与短校验结论，停止仅本次启动的服务；用户要求完成提醒时在完成后发链接。

## 使用模板

- 先读 references/remotion-production.md，再把 assets/remotion-template/ 复制到新的工作目录；只编辑工作副本，不把选题写回已安装的 Skill。
- 模板保留 Skill 主题的 18 幕原稿、图解组件和时间轴示例，不是 AI 记忆参考片的完整源工程；示例是**无声排版预览**，不包含参考配音，不允许直接导出为新选题的完整成片。
- 改写 src/story.json 与 src/project.json；参考所列 visual 类型选择合适图解，缺少合适类型时新增当前主题需要的图解，不生硬套入不相干图形。
- 提供已确认的连续旁白 PCM16 WAV，再运行 scripts/align_narration.py 生成 src/film.json 和 SRT；将音频放在工作目录 public/ 下并正确设置 audio-ref。
- 选择封面、片尾、正文或整片对应 Composition。模板中的封面和头像片尾是可编辑组件，用户头像只能放工作目录；头像缺失时停止片尾制作，不能悄悄用参考视频的身份。
- 本机缺工具时说明具体缺项。只有文件管理能力的宿主可以写稿与分镜，不能宣称完成视频导出；有浏览器但没有媒体解码能力时也不能宣称全片校验通过。

## 验收底线

- 确认旁白没有漏读、截断或意外续写；总体匹配率参考 ≥95%，逐幕 ≥85%，另核对首尾完整。ASR 同音、繁简和英文误识别需单独诊断，不能直接放低门槛。高匹配率本身也不是声音一致的证据。
- 字幕使用原稿，清晰对比，最长两行优先语义换行；逐条检查溢出、时间顺序、切页同步。浅色示例使用深墨字、细线和章节色短标，不默认所有视频必须用同样配色。
- 使用实际 PCM/帧数计算时长；不能只看 MP3 元数据或 API 自报时长。检查响度和峰值并防削波，但不把响度归一称作音色锁定。
- 拒绝未获准覆盖已有输出，禁止将 .env、密钥、签名下载链接、聊天记录、私人绝对路径或真人参考音频打进交付包。
- 无法实际试听或浏览器受限时如实列明限制，不虚构“人工试听/视觉检查通过”。
