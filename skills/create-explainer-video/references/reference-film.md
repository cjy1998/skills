## 叙事与分镜

| 部分 | 幕 | 目的 |
|---|---|---|
| 熟悉场景 | 1–2 | 用反复向 AI 交代要求，引出“可复用方法” |
| 是什么 | 3–5 | 操作手册、提示词与材料组织，澄清不是模型训练 |
| 哪些需求适合 | 6–9 | 重复、稳定、可验收；临时问题与工具权限边界 |
| 怎么做 | 10–14 | 跑通真实任务、迭代、提炼、目录结构、换例验证 |
| 怎么用 | 15–18 | 按宿主安装、明确调用、总结、开放式互动问题 |
| 关注片尾 | 最后4秒 | 头像弹入 → 按钮出现 → 光标轻点 → 扩散圈 |

复用结构，不把其他主题硬塞进 Skill 例子。模板里的 `visual` 是可编辑图解组件，不是素材库能自动理解任何口播的承诺。

## 视觉系统

- 暖白背景 `#F3F2EC`；深墨正文 `#142823`；辅助灰绿 `#66756D`。
- 青柠 `#C6F39F` 为主要强调；珊瑚 `#F6A488` 用于提醒；边线 `#D4DCD1`。
- 中文 Noto Sans SC，等宽字按宿主字体替代。新宿主须重新检查换行。
- 画面上部是品牌、章节和标题；中部是图解；下部保留字幕和页码。字幕深墨字、暖白底、细上边线和短色标，避免突兀的纯黑大字幕条。
- 先看一个内容页，确定配色和层级后再做全套。新选题可以换视觉方向，但封面、正文与片尾保持同一套配色、字体和图形语言。
