# 参考成片：AI 到底怎么记住你？

## 文件与用途

- [关注片尾版视频](../assets/reference/AI记忆-关注片尾版.mp4)：233.2 秒，1080×1920，30 fps，H.264 / AAC，6996 帧，约 13.9 MB。
- [独立封面](../assets/reference/AI记忆-封面.png)：1080×1920 PNG，与正文同一视觉系统，不作为视频开场插入。
- 正文 18 幕、133 条字幕、6876 帧；追加无声关注片尾 120 帧（4 秒）。正文完整连续旁白实际 PCM 时长 227.808 秒，时间轴包括开头 8 帧、结尾 33 帧留白。
- 参考声线：百炼 `qwen-audio-3.1-tts-plus`，`longanlingxin_v3.1`。本片音色与语速经跨分镜试听确认，不是所有新视频的默认声音。
- 本片一次生成完整连续旁白；本地 ASR 总体覆盖率约 96.46%，最低单幕约 88.52%，首尾对齐。统计结果不代替听感验收。

参考成片已做全片解码、浏览器首中尾及拼接处播放检查，并查看实际导出视频的关键帧和最终帧；拼接未重编码正文画面，正文 10746 个 AAC 编码包哈希完全一致。它是制作效果参考，不是对新模板、新稿件或其他平台兼容性的保证。

## 叙事与分镜

| 部分 | 幕 | 目的 |
|---|---|---|
| 熟悉场景 | 1–2 | 从周报语气换会话后失效，引出工作台、便签、资料柜三个比喻 |
| 当前上下文 | 3–5 | 说明本次输入、窗口容量与历史摘要；聊天记录存在不等于本次全部读取 |
| 持久记忆 | 6–8 | 保存偏好、下次按需读取；写入文件不代表自动生效 |
| 知识库与 RAG | 9–12 | 检索相关段落后回答，不是重新训练；仍需检查来源与完整性 |
| 三者配合 | 13–15 | 用周报串联本周信息、长期偏好与制度文档，最终都要进入当前上下文 |
| 排查与边界 | 16–17 | 检查信息是否保存、读取及被截断，提醒隐私与删除边界 |
| 总结与提问 | 18 | 对照三种信息用途，询问最希望 AI 长期记住什么 |
| 关注片尾 | 最后4秒 | 头像弹入 → 按钮出现 → 光标轻点 → 扩散圈 |

复用“熟悉场景 → 分清概念 → 组合使用 → 边界 → 互动”的结构，不把其他主题硬塞进本片比喻。`assets/remotion-template/` 仍保留 Skill 主题的 18 幕无声排版示例，不是本片的完整源工程；制作新题材时需改写原稿、配色与图解，不能只替换口播。

## 视觉系统

- 浅灰白背景 `#F5F7F8` 与低对比点阵；深墨蓝正文 `#17354B`；辅助灰蓝 `#6B7F8D`。
- 青绿 `#17867D` 为主要强调；淡绿 `#E5F1ED`、淡蓝 `#EAF0F6` 与便签黄 `#F8F0D9` 区分信息角色；边线 `#D8E2E6`。
- 中文 Noto Sans SC，等宽字按宿主字体替代。新宿主须重新检查换行。
- 画面上部是品牌、章节和标题；中部是工作台、便签、资料柜及流程图；下部保留字幕和页码。字幕用深墨字、细上边线与短色标，优先语义换行，避免突兀的纯黑大字幕条。
- 封面用三个物件与连线建立关系，正文逐层展开，片尾沿用点阵、字体和青绿按钮，不增加未经确认的旁白或背景音乐。
- 先看一个内容页，确定配色和层级后再做全套。新选题可以换视觉方向，但封面、正文与片尾保持同一套配色、字体和图形语言。
