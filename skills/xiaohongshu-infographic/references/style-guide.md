# 八种风格规范

所有页面 1080×1440（3:4）。每次新任务先咨询用户选择，选项附适用内容；本次请求已明确指定风格则直接使用。同一任务的修改沿用当前选择，不从记忆中强行设默认。

## 整套一致性

封面、产品页、教程页和总结页必须复用同一 STYLE_ID 的配色、字体层级与图形语言。只改变布局和信息密度，不改成另一种视觉。封面标题更大、内容更少；正文装饰更轻，正文不发光、不故意模糊，代码保持等宽。

新增六种主题默认封面与正文同明暗模式。既有 tech 保留深蓝封面和浅灰正文，二者使用同一深蓝＋薄荷体系。统一指同一视觉系统，不强求每个区域背景完全同色。

检查配对预览时逐项看：背景与强调色是否同一色板；同级标题字体、字重是否一致；编号、线宽、边框、阴影、装饰是否来自同一套；页脚、页码、边距是否连贯。任一项跑偏则修改后重导。

## 风格一：暖白＋深墨＋青柠杂志风

STYLE_ID = magazine。

| 用途 | 色值 |
|---|---|
| 暖白底 | #F6F5EF |
| 深墨正文 / 深色费用区 | #252B23 |
| 辅助文字 | #73796E |
| 青柠高亮 | #DAF58A |
| 网格 / 分隔线 | #E8E9DF / #DADDD0 |

- 封面：暖白细网格，左上大数字青柠块、大标题和两句主张；下部白色双列内容清单，底部深墨导读条。目录最多六项，禁止价格。
- 内容页：产品大标题＋厂商副标题；一句两行主张，右侧简洁纸张插画；中部白色面板内三条功能，编号、标题、短句与细线分隔；底部深墨双栏费用区，青柠福利条。
- 不恢复旧的蓝色字、大面积浅蓝说明卡。留白、字号和语义层级比装饰更重要。

## 风格二：深蓝＋薄荷科技编辑风

STYLE_ID = tech。

| 用途 | 色值 |
|---|---|
| 旧封面深蓝底 / 代码块 | #13243D |
| 内容页浅灰底 | #F1F4F8 |
| 标题正文 | #182B46 |
| 辅助文字 | #687B93 |
| 编号等少量强调 | #3469FA |
| 封面高亮 / 福利条 | #B5F1D2 |
| 网格 / 分隔线 | #E4EAF2 / #DCE4EF |

- 封面保持旧版：深蓝点阵、白色大标题、薄荷绿副标题、单列目录、低对比导读与页脚。禁止价格。
- 内容页重设计：不沿用旧页首大 pill、重复产品条目和整块蓝色文字卡；换浅灰细网格、深色大标题、右侧三节点流程图。
- 功能面板左右分栏：编号与短标题在左，解释在右，细线分隔。正文深色或灰色，蓝色只用于少量编号。
- 费用放两张并列白卡，分别表达免费权益和付费参考；提示用一条薄荷绿横栏。保持内容区域紧凑且清晰，不把标题重复三次。

## 六种扩展风格

以下风格由 render.styles.js 的 EXTRA_THEMES 与四类页面绘制函数统一管理，配色数值以该文件为准。工作副本只选 STYLE_ID 和填 CONTENT，不把某一篇的文案写回风格资源。

### 瑞士极简（swiss）

- 用于横评、结论清单、概念辨析。暖白、近黑与少量红色点睛，平直细线、克制的灰色数字、严格对齐。
- 封面大数字、目录、功能、步骤、总结编号与页码统一使用辅助灰（C.muted），不以高饱和红色抢占标题和正文的层级。保留原有字号、字重与位置，红色只用于少量标签和强调线。
- 封面以大字、数字和目录形成编辑层级；内容页用对照分栏、横向分隔，不增加圆角彩色卡片。总结继续用同样的灰色编号和黑色标题。
- 不将它变成换了红色强调的暖白杂志模板；减少插画、阴影与装饰。

### 粗线条海报（brutal）

- 用于避坑、误区纠正、前后对比。奶油底、黑色粗框、黄色强调，少量蓝色或粉色辅助区。
- 封面、正文、收尾都使用同样的粗边框和硬阴影；封面大字更醒目，正文色块只承载有意义的信息分组。
- 装饰线和贴纸不盖字；不把强调线画成划掉正确结论的删除线。

### 手账笔记（notebook）

- 用于入门教程、学习笔记、操作步骤。米色纸底、墨绿文字、黄色荧光笔、柔和便签。
- 各页保留纸张横线、页边线、勾选与手绘标注；封面可以用更大范围的荧光笔，正文保留可读黑体，不强行用难辨手写字体。
- 留出装订孔与页边线位置，代码区不被这些装饰穿过。

### 工程蓝图（blueprint）

- 用于原理解释、架构与流程。整套深蓝网格、浅蓝白字、青色节点、工程式细线。
- 封面用简化关系和大标题，内容页用有实际含义的节点、连接和标注；总结延续同一框线与编号。
- 连线表示真实关系，不为了好看编造技术依赖；不能突然换成白底商务卡片。

### 暗黑霓虹（neon）

- 用于编程工具、自动化、前沿 AI 话题。炭黑背景、青紫强调、浅色正文与终端式面板。
- 封面和后续页统一青紫细光线、圆角面板与等宽辅助标签；光效仅在边框或装饰，不用于长段文字。
- 发光不能降低文字对比度。功能描述、版本和条件不使用过暗的灰字。

### 复古报刊（newspaper）

- 用于行业观察、产品故事、发展时间线。米色纸底、深棕文字、红色批注、宋体报头与细分栏。
- 所有页面的标题使用 Songti SC / STSong，同级字重一致；正文仍用 PingFang SC，提高手机阅读清晰度。页眉名称来自 CONTENT.brand，不硬编码某个报刊名称。
- 封面形成报头、大标题和导读层级；正文使用分栏、引述或分隔线，收尾保留同样编辑语言。
- 不照搬真实报纸的小字密集排版；长代码必须独占足够宽度，不能塞进窄栏。

## CONTENT 字段

先设置 STYLE_ID 为 magazine、tech、swiss、brutal、notebook、blueprint、neon、newspaper 之一。null 是未选择状态，渲染会明确停止，不能把模板顺序当作默认。HTML 必须先加载 render.styles.js，再加载 render.js；两份脚本一并复制。

CONTENT.brand / footer：栏目和资料说明。

CONTENT.cover：
- count：工具或内容项数，建议 1–6；title：接在数字后的标题，深蓝版连数字显示；subtitle：深蓝版的大副标题，暖白版的说明句。
- headline：暖白与六种扩展风格的两句封面主张，数组长度 2；所有风格都填写，便于换主题时保留内容。
- badge：深蓝版顶部标签；scope：阅读范围、编号说明或选型建议，不写价格。
- items：name / detail，最多六项，目录里也不写价格。

CONTENT.details：按输出顺序定义每页。
- kind:product：name、slug、sub、headline（两句）、tags（三个短英文词）、features（三组 [标题,解释]）。
- freeTitle / freeNote：免费权益与限制；paidLabel / price / priceUnit / paidNote：付费参考值、周期和条件。
- promoLabel / promoMain / promoNote：重点提示。产品活动用资格、有效期和当前状态，不确定时写待确认；非商业主题改为关键结论。
- kind:guide：title、slug、sub、sections；每节 title / body，可带 code / codeTitle。代码后立即解释各项，不集中放页尾。

CONTENT.closing：两句 title、sub、tableTitle、rows（最多六组 [名称,任务,说明]）、tip、warning、note。

模板示例没有真实定价；生成作品时必须替换占位文字，删除不适用的费用/促销概念。技术密度高时用 guide 布局，最多三节并就近解释命令。

## 质检与交付

- text 的 max 参数必须约束单行宽度；para 和 code 也检查页高。diagnostics 有任何条目都不交付。
- 逐张目检字号、中文、左右分栏、页脚与插图；console 不得有错误。确认导出结果的风格与选择一致。
- contact-sheet.png 保持每页 3:4 比例，不把竖图压成正方形。
- 导出文件 NN-slug.png；发布包含发布图片/、总览预览.png、小红书笔记文案.txt。张数和尺寸用 verify_and_pack.py 验证。
- 内容或视觉方向需要重新确认时，先给单页样稿，用户认可后再批量扩展。
